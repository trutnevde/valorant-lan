# BUGLIST — регресс-зоны и расхождения канон ↔ код

Ведётся с Эпохи 15 (Фаза 0). Гейт (`npm run gate`) обязан ловить всё из раздела «Регресс-зоны».

## Регресс-зоны (гейт проверяет всегда)

- **Боты:** застревания, проход сквозь стены, кучкование на планте, мгновенный автоаим, прицел/скиллы сквозь стены (нужен LOS-чек), человеческая скорость доворота.
- **Ульта:** жёсткий кап заряда.
- **Ники/подсветки:** не видны сквозь дым и стены.
- **Прицел:** одинаков во всех браузерах (нормализация devicePixelRatio).
- **FPS-пожиратели:** смоки, «Финальный банкет», яркое солнце/bloom.
- **Сова:** снаряды летят физически (втыкаются в стены), эффект — по прямой видимости.
- **Смоки:** полностью плотные, в т.ч. изнутри; ослепляют и ботов.

## Расхождения канон (DESIGN.md) ↔ код (найдено в Фазе 0)

1. **Ульта — источники заряда.** Канон (override игрока): заряд ТОЛЬКО за киллы. Код (`server.js`): `gainUlt` вызывается также за плант, за смерть (victim), за ability-килл. → Привести к «только киллы» в Фазе 3.
2. **Пассивка Иры.** Канон: убийство создаёт хил-зону у трупа врага для союзников. Код: не реализовано. → Фаза 3.
3. **Пассивки / сигнатурки / твисты всех агентов.** Канон (Эпоха 15): описаны. Код: не реализовано. → Фаза 3.
4. **Гера (анти-смокер, 10-й агент).** Канон: в ростере с полной анти-смок системой. Код: агента нет. → Фаза 3.
5. **Звук — только сэмплы.** Канон/правило #4: осцилляторный синтез запрещён. Код (`audio.js`): часть звуков — сэмплы (выстрелы/шаги/перезарядка/UI/скиллы), но остаются синтез-фолбэки и тематические синтез-«голоса» (курица Иры, ржание Конилия, бип шипа синусом). Ассеты лежат в `assets/sfx/` (канон ждёт `assets/audio` + `ATTRIBUTION.md`). → Фаза 2: полная замена, удалить осцилляторы, завести `ATTRIBUTION.md`.
6. **Инвентаризация неполна.** Заполнены: экономика, арсенал, кит Дениса/Иры/Фафика/Совы. Осталось транскрибировать из `shared.js`: точные числа Артемия, Макса, Конилия, Вовы, Санька (способности/заряды/радиусы). → добить в отдельном инвентаризационном проходе.
7. **Модели персонажей.** Канон: единый CC0-скелет + анимации, капсульные хитбоксы неизменны. Код: процедурные человечки + опциональный GLTF-дропин (KayKit убран по просьбе игрока). → Фаза 2.
8. **Пресеты сложности ботов.** Канон: лёгкий/средний/жёсткий в `shared.js` + переключатель в лобби. Код: одиночный набор констант в `botShoot`. → Фаза 4.
