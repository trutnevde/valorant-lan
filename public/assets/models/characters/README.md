# Модели персонажей (GLTF) — drop-in

Сюда кладутся **скелетно-анимированные** модели агентов в формате `.glb`.
Если модели для агента нет — игра автоматически рисует процедурного человечка (как раньше).
Никакой регрессии: пустая папка = старое поведение.

## Как подключить свою модель (например, из Mixamo)

1. Возьми риггнутого персонажа на [mixamo.com](https://www.mixamo.com) (бесплатно, нужен вход Adobe).
2. Накинь анимации и **скачай в .glb** (Format: glTF Binary). Желательные клипы в одном файле
   или отдельными — важно, чтобы в именах встречалось:
   - `idle` — стойка
   - `walk` — ходьба
   - `run` — бег (необязательно)
   - `death` — смерть (необязательно; без него модель просто замирает)
3. Назови файл по **id агента** и положи сюда:
   `artemiy.glb`, `max.glb`, `vova.glb`, `sanek.glb`, `denis.glb`, `ira.glb`, `fafik.glb`, `koniliy.glb`
4. Пропиши имена в `public/assets/manifest.json`, добавив массив `models`:
   ```json
   "models": ["artemiy", "max", "denis"]
   ```
   (перечисляй только тех, для кого реально положил `.glb`).
5. Готово — эти агенты будут рендериться настоящей моделью со скелетной анимацией,
   а хитбоксы (голова/тело/ноги, с хедшотами) навешиваются автоматически.

## Быстро посмотреть, как это выглядит, без своих моделей

В консоли браузера (F12) до старта матча:
```js
window.USE_DEMO_MODELS = true
```
Тогда всем агентам подставится демо-модель `_demo.glb` (RobotExpressive из three.js, **CC0**).
Это тех-демо пайплайна, а не финальный арт — робот один на всех, костюмы агентов при этом прячутся.

## Технические заметки
- Модель автоматически масштабируется к росту ~1.8 юнита, ступни ставятся на землю.
- Материалы слегка тонируются в цвет агента (командная/агентская идентичность сохраняется).
- Развёрнута лицом по −Z (как процедурный человечек). Если твоя модель смотрит не туда —
  поправь `model.rotation.y` в `public/js/loaders.js` (`makeGltfCharacter`).
- Всё офлайн: `GLTFLoader`/`SkeletonUtils` вендорены в `public/js/three/`, модели — локальные файлы.
- Лицензия `_demo.glb`: CC0 (three.js examples, автор Tomás Laulhé / Quaternius).
