# ⚔️ VALORANT: ЛОКАЛКА

Тактический шутер от первого лица в браузере — до **5 на 5** по локальной сети или через VPN,
с ботами и режимом против ИИ. Раунды, экономика, закупка, шип, 9 агентов с ультами, 3 карты.
Первый до **5 раундов**. Всё на локальном движке — интернет не нужен, звук синтезируется, никаких файлов-ассетов.

> Хронику разработки по эпохам смотри в [VERSIONS.md](VERSIONS.md).

> 🎮 **Godot-порт:** в папке [`godot/`](godot/) на ветке `godot-port` идёт перенос игры на Godot 4
> (нативный exe, лучшая графика/звук при полном паритете механик). Веб-версия остаётся живой и
> главной, пока порт не догонит. План — `MIGRATION-GODOT.md`, правила порта — `godot/CLAUDE.md`.

## 🚀 Быстрый старт (нужен один раз)

Нужен только [Node.js](https://nodejs.org) (LTS). Дальше в папке проекта:

```bash
npm install      # поставить зависимости (один раз)
npm start        # запустить сервер
```

Сервер напечатает адреса:
```
Локально:  http://localhost:27015
По сети:   http://192.168.x.x:27015   <- в одной Wi-Fi/LAN
По сети:   http://26.x.x.x:27015       <- это адрес Radmin VPN
```

- **Хост** (кто запустил сервер) играет, открыв в браузере `http://localhost:27015`.
- **Друг** открывает в браузере адрес хоста «По сети» (см. ниже — LAN или Radmin).
- Первый зашедший = **хост лобби** (★): собирает команды, добавляет ботов кнопкой, выбирает карту, жмёт «НАЧАТЬ МАТЧ».
- При первом запуске Windows спросит про брандмауэр — разреши **Node.js** в **частных сетях**.

Браузер — Chrome/Edge/Firefox. Кликни по игре, чтобы захватить мышь (Esc — отпустить).

## 🌐 Играть с другом через Radmin VPN

Radmin VPN делает вид, что вы в одной локалке (выдаёт адреса `26.x.x.x`).

1. Оба ставите **Radmin VPN**. Один создаёт сеть (Create), второй присоединяется (Join) по имени+паролю. Статус друг напротив друга должен быть **зелёным**.
2. **Хост:** `npm start` → скопируй строку с адресом **`26.x.x.x:27015`** (её печатает сервер).
3. Разреши Node.js в брандмауэре (частные сети), иначе друг не подключится.
4. **Друг:** открывает в браузере `http://26.x.x.x:27015` (адрес хоста) — поле «СЕРВЕР» подставится само, жмёт «В БОЙ».

**Не коннектится?**
- Друг должен вводить именно **26.x.x.x** (не 192.168 — тот только для физической локалки).
- 90% проблем — брандмауэр хоста. Разреши Node.js в частных сетях или временно выключи фаервол.
- Оба реально в одной Radmin-сети, статус зелёный.
- Порт занят? `set PORT=27020 && npm start` (cmd) → друг заходит на `26.x.x.x:27020`.

В одной Wi-Fi/LAN всё то же самое, только друг вводит адрес **192.168.x.x:27015**.

## 🎮 Режимы

- **Соло против ботов** — зайди один, добавь ботов в обе команды, старт.
- **1v1 … 5v5** — сколько людей зашло, так и играете; недостающих добери ботами.
- Команды до 5. Любой может сменить команду до старта.

## 🕹️ Управление

- **WASD** движение · **Shift** тихий шаг (бесшумно!) · **Ctrl** присед (бесшумно) · **Пробел** прыжок
- **ЛКМ** огонь · **ПКМ** прицел (у снайперок — зум-скоуп) · **R** перезарядка · **1/2/3** оружие
- **C / Q / E** способности · **X** ульта · **B** закупка · **Tab** счёт · **Enter** чат
- **4 (держать)** установить шип · **F (держать)** обезвредить

Стрельба глубокая: отдача уводит прицел (тяни вниз), в движении разброс растёт (стой при стрельбе),
с ножом бегаешь быстрее, попадание замедляет. **Боты слышат бег и выстрелы** — шифт/присед спасают.
