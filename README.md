# VALORANT: ЛОКАЛКА v2 — до 5 на 5 по LAN + боты

Тактический шутер от первого лица в браузере. Раунды, экономика, закупка, шип,
5 агентов с глобальными ультами, две карты, боты и режим против ИИ.
Первый до **5 раундов**.

## Запуск (хост)

1. Установи [Node.js](https://nodejs.org) (если ещё нет).
2. В этой папке:
   ```
   npm install
   npm start
   ```
3. Сервер напечатает адреса:
   ```
   Локально:  http://localhost:27015
   По сети:   http://192.168.x.x:27015  <- дай эту ссылку друзьям
   ```
4. Открой `http://localhost:27015`, друзья в том же Wi-Fi/LAN — адрес «По сети».
5. Первый зашедший игрок — **хост** (★). Он собирает команды, добавляет ботов,
   выбирает карту и жмёт «Начать матч».
6. При первом запуске Windows спросит про брандмауэр — разреши **частные сети**.

## Режимы

- **Соло против ботов**: зайди один, добавь ботов в обе команды, жми старт.
- **1v1 … 5v5**: сколько людей зашло — так и играете; недостающих добери ботами.
- Команды до 5 человек. Хост распределяет; любой может сменить команду до старта.

## Агенты

| | C | Q | E | X (ульта) |
|---|---|---|---|---|
| **Артемий** (дуэлянт) | Вспышка | Огонёк (лечит) | Стена огня | Второе дыхание: умер → воскрес |
| **Макс** (дуэлянт) | Рывок ×2 | Взлёт ×2 | Порыв +40% скор. | Стальные перья: ножи, килл = обновление |
| **Вова** (смокер) | 🌐 Дым по карте ×3 | Слепящий заряд | Завеса из 3 дымов | 🌐 Орбитальный удар по карте |
| **Санёк** (спец) | Сигналка ×2 | Турель | Кислота | 🌐 Рентген: все враги сквозь стены |
| **Денис** (инициатор) | Тухлая вспышка ×2 | Тухлятина (лужа) | Смрад (смок ×2) | Мясной крюк-кокон: тащит и разделывает |

🌐 — глобальные способности (клик по миникарте). Кокон Дениса можно **отстрелить**
союзникам жертвы (150 HP), как ульту Deadlock.

## Карты

- **Дуэль** — плоская классика: два сайта, мид, много укрытий.
- **Высота** — вертикаль: центральная башня и сайт B на платформе, лестницы.

## Управление

- **WASD** движение · **Shift** тихо · **Ctrl** присед · **Пробел** прыжок
- **ЛКМ** огонь · **ПКМ** прицел (снайперки) · **R** перезарядка · **1/2/3** оружие
- **C / Q / E** способности · **X** ульта · **B** закупка · **Tab** счёт · **Enter** чат
- **4 (держать)** установить шип · **F (держать)** обезвредить

Отдача — как в CS/Valorant: спрей уводит прицел вверх и по дуге, тяни мышь вниз.

## Оружие

15 стволов по категориям: пистолеты (Классик/Призрак/Шериф), дробовики (Дробаш/Судья),
ПП (Стингер/Спектр), пулемёт (Арес), винтовки (Бульдог/Гвардеец/Фантом/Вандал),
снайперки (Маршал/Оператор). У каждого своя отдача, разброс, спад урона по дистанции.
