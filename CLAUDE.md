# CLAUDE.md — Valorant LAN

Браузерный тактический шутер (клон Valorant «по мотивам») для игры с друзьями 1v1–5v5 по LAN / Radmin VPN. Node.js + ws сервер, three.js клиент (вендорен, importmap), после `git pull` работает полностью офлайн.

Этот файл — правила работы над проектом. Гейм-дизайн-канон — в `DESIGN.md`. Хроника версий — в `VERSIONS.md`.

## Структура

- `server.js` — авторитарный сервер: HP, экономика, раунды, шип, валидация способностей, боты
- `public/js/shared.js` — **единственный источник истины по числам**: оружие, персонажи, карты, правила
- `public/js/` — `main.js` (вход/сообщения), `player.js` (движение/коллизии), `weapons.js` (стрельба), `remote.js` (модели противников), `abilities.js`, `hud.js`, `effects.js`, `map.js`, `audio.js`, `postfx.js`, `loaders.js`, `net.js`
- `tools/` — валидатор карт, скрипты ассетов; `test/` — smoke, бот-матчи
- `public/assets/` — вендоренные модели/звуки/текстуры + `manifest.json`; лицензии в `ATTRIBUTION.md`

## Команды

- `start.bat` (или `npm start`) — сервер; печатает `localhost` и Radmin-адрес `26.x.x.x` для друга
- `npm run gate` — обязательный прогон перед **каждым** коммитом (см. Железные правила)

## Железные правила

1. **Тест-гейт перед каждым коммитом**: smoke-тест протокола + валидатор связности всех карт + headless бот-матч (0 застреваний, 0 проходов сквозь стены, точность ботов в допустимом коридоре) + hitreg-санити с фиксированным сидом. Гейт красный → чинить, не коммитить. Если гейта ещё нет — построить его раньше любых фич.
2. **Одна фаза = одна подсистема.** Не смешивать графику, ботов и баланс в одном коммите. Завершил фазу → гейт → коммит → тег → запись в `VERSIONS.md` (что / зачем / как проверено).
3. **Ветка `saga`, теги `vX.Y.Z-имя`.** Регресс должен биcектиться по тегам.
4. **Звук — только сэмплы.** Синтез осцилляторами запрещён (никаких «пик-пик»). Сэмплы CC0, лежат в `public/assets/audio`, перечислены в `ATTRIBUTION.md`. Звук — игровая механика: боты слышат шаги, Shift и присед бесшумны.
5. **Перф-бюджет: 60 FPS на средней видеокарте.** Любой новый эффект — с бюджетом и авто-фолбэком (клавиша P). Смоки полностью непрозрачны, в том числе изнутри.
6. **IP-гигиена:** никаких точных копий чужих карт, персонажей и логотипов — только «по мотивам». Ассеты только CC0 или эквивалент, с записью в `ATTRIBUTION.md`.
7. **Информация — через звук и анимацию, не текстом.** Никаких надписей вида «половина зафиксирована» и подобных подсказок состояния.
8. **Не работать молча дольше ~2 минут** — короткие апдейты по шагам между операциями.
9. **Без мульти-агентных ревью-воркфлоу**, если явно не попросили.
10. **Правки — точечными Edit.** Полная перезапись файла — только при осознанном рефакторинге, отмеченном в коммите.
11. При расхождении `shared.js` и `DESIGN.md` — синхронизировать оба в одном коммите и отметить, что именно поменялось.

## Известные регресс-зоны (гейт проверяет всегда)

Боты: застревания, проход сквозь стены, кучкование при защите планта, мгновенный автоаим, прицеливание/скиллы сквозь стены (нужен LOS-чек). Ульта: кап заряда. Ники: не видны сквозь дым и стены. Прицел: одинаков во всех браузерах (devicePixelRatio). FPS: смоки, «Финальный банкет», яркое солнце. Сова: снаряды летят физически и работают только по прямой видимости.

## Архитектурный компромисс (осознанный)

Попадания и движение считает клиент; сервер авторитетен для HP/экономики/раундов/шипа. Для игры с друзьями — ок. Перевод хитрега на сервер — отдельная будущая эпоха, в текущих фазах сетевую модель и ws-протокол не трогать без необходимости.

## Дистрибуция

GitHub → у друга: `git pull` → `start.bat`. Никаких CDN и загрузок в рантайме — всё вендорено в репозитории.
